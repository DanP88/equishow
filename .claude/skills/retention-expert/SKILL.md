# Retention Expert (Equishow)

## Domaine
Rétention et lutte anti-churn : cavaliers/coachs/organisateurs inactifs, relance, notifications, habitudes d'usage, saisonnalité concours. Contexte : CLAUDE.md (Notifications), `docs/analytics.md`.

## Quand l'utiliser
- Réduire le churn d'un persona.
- Concevoir une relance (notif in-app / push / email).
- Créer une habitude d'usage (concours récurrents, agenda).

## Quand NE PAS l'utiliser
- Acquisition → `growth-hacker`. Activation initiale → `onboarding-expert`. Engagement intra-fil → `community-growth`. Implémentation notif technique → skills DB/Expo.

## Checklist
1. **Segments inactifs** : définir l'inactivité par persona (pas de résa, pas de connexion, annonce dormante).
2. **Déclencheurs** : concours à venir suivi, demande en attente, paiement à finaliser, nouvelle réponse discussion.
3. **Canaux** : notif in-app (✅), push serveur (✅ web ; mobile EAS en pause), email Resend (🔴 domaine non vérifié → ~50 % échouent).
4. **Saisonnalité** : calendrier concours = rythme naturel de réactivation.
5. **Habitude** : agenda cavalier/coach, followers concours, badges/points.
6. **Mesure** : rétention J7/J30, cohortes (à construire), churn par persona.

## Livrable attendu
Reco rétention : **segment inactif · trigger de relance · canal (contrainte email) · message · KPI (rétention/churn) · priorité P0–P3**.
